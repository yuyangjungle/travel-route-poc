# M4-001 首轮用户验证计划

状态：Technical validation complete. User validation intentionally deferred；计划保留，尚未执行。  
最后更新：2026-09-17

## 实验目的

用 5–8 名目标用户的行为和解释，判断当前模拟数据原型是否值得进入下一轮验证。目标是发现理解障碍和早期价值信号，不是证明产品成功、市场规模或产品市场契合。

技术正确性与用户价值是两项不同结论：M2 已证明搜索结果在固定数据和离散模型内与独立穷举一致；M4-001 要观察用户是否看懂、是否愿意进一步核对推荐，以及工具是否改变规划过程。

## 核心研究问题

1. 用户能否区分最便宜、最少折腾、偏好最匹配和综合推荐？
2. 用户能否用实际路线、价格、交通和停留信息解释选择，而非只接受总分？
3. 用户是否发现原本没有想到、但愿意继续核对的组合？
4. 必去地点、预算和无解结果是否被正确理解？
5. 与日常规划过程相比，哪些步骤显得更省力、相同或更费力？

## 假设与可验证范围

| 假设 | 来源 | 5–8 人可获得的证据 | 本轮不能回答 |
| --- | --- | --- | --- |
| 用户愿意为更好组合调整日期或增加目的地 | A-01 | 是否选择并愿意继续核对非预设组合；选择理由 | 目标市场中愿意调整的比例 |
| 显式评分和标签能支持有用排序 | A-03 | 是否理解类别、是否质疑分数、选择是否引用分项 | 权重对所有用户或真实市场最优 |
| 开口程和不同返程机场可接受 | A-05 | 是否注意并接受 PVG/HGH 不同起终点；担忧原因 | 大规模需求比例和地面接驳真实性 |
| 小规模任务与门槛能支持探索性决策 | A-09 | 任务能否暴露稳定问题、记录是否完整 | 统计显著性或可泛化效应量 |
| 目的地标签足以支持灵感阶段 | A-10 | 标签是否帮助初筛、还缺哪些决策信息 | 活动级规划或安全可行性 |
| 无解说明能维持正确心智模型 | FR-08/US-06 | 是否理解“样本内无解”与“现实无航班”的区别 | 真实航班覆盖率 |

以下假设不能由本轮模拟数据解决：A-02 人工参数真实性、A-04 真实票价口径、A-06 目标规模性能、A-07 现实接驳、A-08 报价覆盖和可复核性。它们保留给真实数据或规模验证。

## 参与者与样本

- 5–8 人，过去两年内自行规划过亚洲自由行。
- 曾比较多个目的地、日期或机场；以上海或杭州周边出发者优先。
- 排除只购买固定日期单一往返且从不参与规划的人。
- 样本用于发现模式和严重问题，不代表总体。

不收集姓名、邮箱、IP、设备信息、证件或精确历史行程。主持人只分配 P01–P08 匿名编号。

## 方法

- 形式：一对一主持测试，30–40 分钟，可远程屏幕共享。
- 材料：[用户测试手册](user-testing.md)、公开 Pilot、应用下载的 `pilot-record-v1`、[结果模板](../pilot_results_template.json)。
- 流程：测试前问题 → 4 项标准任务 → 测试后问题。
- 主持人只读参与者任务，不透露预期路线、观察目标或通过条件。
- 每项从读完任务开始计时，到参与者作出选择或明确拒绝并生成记录为止。
- 允许参与者拒绝所有推荐；这不是失败。
- 如主持人必须提示，记录提示内容、发生位置和次数。

任务顺序固定为发现 → 约束 → 取舍 → 无解，便于先观察自然理解，再逐步增加约束。由此产生的学习效应必须在分析中注明；不比较后续任务和前一任务的绝对用时来推断界面改善。

## 证据来源

1. **产品行为：** 场景、结果状态、展示方案、所选路线、任务时间。
2. **观察行为：** 犹豫、回退、比较、展开详情、提问、误解和主持人提示。
3. **参与者意见：** 信任、有用性、愿意核对、困惑和缺失信息。
4. **上下文：** 日常工具和自述规划过程，仅用于解释，不作为精确基线。

## 指标与预设门槛

以 [Pilot 指标](pilot-metrics.md)为权威：

- 理解：至少 80% 能解释 T3 的收益/代价、T4 的数据边界，并解释至少 3/4 推荐类别。
- 信任：至少 60% 信任评分 ≥4 且能指出仍需外部核对的信息。
- 有用性：至少 60% 用途评分 ≥4，并能选择或明确拒绝一条路线。
- 非直觉发现：至少 60% 发现并愿意考虑一个原本没想到的组合。
- 规划努力：至少 80% 核心任务无需提示完成；报告任务用时中位数、提示数和更快/更慢的具体步骤。

小样本门槛是决策规则，不是总体比例估计。

## 容易误导的指标

本轮不报告或不据此下结论：

- NPS、满意度均值、“喜欢产品”的人数等虚荣指标。
- 注册、留存、转化、付费意愿或产品市场契合。
- 点击量、停留时长或下载次数作为价值替代指标。
- 固定模拟价格带来的真实节省金额、可购买率或市场覆盖。
- 5–8 人百分比的显著性、置信区间或人群外推。
- 接受推荐即证明排序正确；用户可能因默认位置、题目学习或模拟情境而选择。
- 以自述日常耗时作精确基线，并声称规划时间降低 30%。没有同任务、同数据、交错顺序的配对对照前，只能报告方向性努力证据。
- 固定任务完成率作为自然使用留存或复访意愿。

## 决策规则

- **进入真实报价小样本：** 理解门槛通过，且有用性和非直觉发现均达到 60%；没有人把模拟报价当成实时可购买价格。
- **先修正表达再复测：** 价值信号存在，但多个参与者在同一术语、分数或无解边界上失败。
- **重新审视目标用户或价值假设：** 多数人正确理解后仍不愿核对任何新组合，或认为完整复查工作没有减少。
- **停止扩大投入：** 推荐持续只产生用户已知路线，或用户认为新增路线的交通代价不可接受且无决策帮助。

所有决策必须引用行为、意见和样本限制。分析方法见 [M4 分析指南](m4-analysis-guide.md)。
