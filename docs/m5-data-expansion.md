# M5 模拟数据扩展

状态：M5-001 已完成。全部内容均为模拟数据，不可用于购票或现实目的地建议。  
最后更新：2026-09-16

## 目的与边界

`data/m5` 用于回答一个技术问题：现有确定性搜索能否在接近 MVP 目录规模的网络上保持正确、可复现，并暴露实际性能边界。它不是 M1 正确性基准的替代品，也不改变 M2 oracle。

| 项目 | M5 数据 |
| --- | ---: |
| 目的地 | 40 |
| 机场 | 43（3 个国内出发机场 + 40 个目的地机场） |
| DestinationAccess | 40 |
| 单程报价 | 3,935 |
| 区域 | 亚太代表性城市、枢纽、海岛与远程目的地 |
| 季节快照 | 2027 年 1、4、7、10 月 |
| 密集搜索月份 | 2027 年 10 月 |

目录包含 PVG、HGH、NKG，以及东京、首尔、曼谷、新加坡、吉隆坡、马尼拉等枢纽，Semporna、Bali、Phuket、Cebu、Palau、Maldives、Fiji 等海岛/潜水地点，并加入澳大利亚和新西兰边缘节点。地点名称和 IATA 代码仅用于构造可读网络；所有价格、时刻、路线、接驳和推荐参数均由生成器虚构。

## 可复现生成

[generate.py](../data/m5/generate.py) 不读取网络、不使用随机数，以固定目录和整数公式生成六个 JSON 文件。已生成文件纳入项目，普通运行无需先执行生成器。

```powershell
py -3.12 -m data.m5.generate --check
py -3.12 -m data.m5.generate
```

`--check` 对比每个文件的 UTF-8 字节内容；任何目录、公式或序列化变化都会失败。数据清单的 `coverage_kind` 为 `synthetic`，每个目的地和接入映射标记 `is_mock=true`，每条报价标记 `source_type=mock` 和生成器来源。

## 真实性维度

### 季节价格与目的地季节分

同一 PVG–目的地路线在 1、4、7、10 月使用不同固定价格系数。目的地另有 12 个月的 `season_scores_by_month`；海岛、城市和文化地点使用不同模拟曲线。两者分别表示机票价格变化和体验季节性，搜索评分只使用既有的目的地季节分，不新增价格推断逻辑。

### 停留建议

各目的地按模拟类型设定 `min_stay_nights`、`recommended_stay_nights`、`max_stay_nights` 和 `min_usable_minutes`。推荐停留为 2–6 夜，远程海岛通常更长。数值只用于测试停留收益饱和与可行性。

### 连接难度

报价同时包含直飞和一次受保护联程。远程机场的部分国内往返报价通过模拟枢纽连接，因此现有 `connection_count`、总在途分钟和交通负担公式可以反映更困难的路线。数据没有自行转机、机场间换乘或真实最低衔接时间。

### 偏好标签

标签扩展为 `island`、`diving`、`food`、`culture`、`nature`、`city`、`relaxation`。每个目的地包含完整 0–100 字典，来源是固定类型模板。`score-v1` 公式和权重语义未改变。

## 性能场景

[scales.json](../benchmarks/m5/scales.json) 中每个案例都声明产品假设。三个案例从同一目录按目的地前缀构造嵌套子图；首程来源和返程机场由目的地位置固定，保持开放口机会；邻接数和可选停靠数逐级增加。

| 案例 | 目的地 / 机场 | 可选停靠上限 | 产品假设 |
| --- | ---: | ---: | --- |
| small | 8 / 11 | 2 | 聚焦区域集合可由精确搜索交互比较 |
| medium | 18 / 21 | 3 | 更广的亚洲枢纽与海岛集合仍可用 |
| large | 40 / 43 | 4 | 完整 M5 目录会暴露穷举与全量留存边界 |

性能子集不等于全部 3,935 条报价：只取 10 月、固定首返程规则和逐级增加的邻接边，以便把规模变化解释为网络与停靠扩展，而不是季节快照数量变化。完整目录仍用于加载、来源和模式校验。

## 已验证事项与限制

- 40 个目的地、43 个机场与全部外键通过现有 Dataset 校验。
- 同一路线四季价格不同；停留、季节、标签和 0/1 次中转均有变化。
- 生成器字节复现测试通过，搜索输入顺序变化不改变 small 结果。
- M1 文件、20 个场景、内容锁及 M2 oracle 未改动。

这套数据不能验证真实航线覆盖、价格分布、时刻可执行性、签证、行李规则、酒店或当地交通。缺少某条边只表示模拟目录没有该报价。
