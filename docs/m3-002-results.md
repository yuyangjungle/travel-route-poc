## 验证记录

验证结果：

- 本机完整测试：75 项通过。
- M1 校验：20 个场景通过，固定内容摘要未改变。
- M2 搜索：20 个场景完整可行集与 Pareto 集继续匹配独立 oracle。
- 干净环境：一次性 Python 3.12 虚拟环境从 `requirements.txt` 安装后，75 项测试全部通过，Streamlit 版本为 1.44.1；临时环境自动删除。
- 真实浏览器：默认推荐、类别说明、路线选择、反馈提交、实际 JSON 下载和无解解释均可操作；下载文件可解析且包含 2 个展示方案与所选路线，浏览器错误与控制台为空，服务标准错误为空。
- 记录内容：纯函数测试和 Streamlit AppTest 验证选择 ID、自动字段、主观字段、JSON 往返及无解记录。

复现命令：

```powershell

py -3.12 scripts/verify_clean_environment.py
```

## 已知限制

- 公共部署仍需仓库所有者完成 GitHub 与 Streamlit 的账户操作。
- 无数据库；参与者必须下载 JSON，主持人负责收集和汇总。
- 刷新或切换场景会重置任务计时，页面关闭会丢失未下载反馈。
- 固定数据仅覆盖 2026 年 10 月、9 个机场、6 个目的地和 15 条模拟报价。
- 本轮没有真实用户结果，也没有配对人工规划基线。

## 下一决策点

执行 5–8 人测试并按预设指标汇总。只有理解和初步价值信号达到门槛，才进入少量人工真实报价验证；不因 Pilot 反馈直接改搜索算法。
