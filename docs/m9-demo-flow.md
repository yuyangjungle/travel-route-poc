# M9 可复现产品演示流程

日期：2026-09-22。用于产品面试、OTA 交流和内部交付检查；不作为真实用户验证结果。

本流程区分自然语言功能演示和固定条件算法演示。模型抽取具有变化性；固定结构化示例用于复现行程。全部价格、资料和交通参数均为模拟数据。

## 准备

1. 按 [README](../README.md) 安装固定依赖。公开 Web 入口为 `server.py`，本地运行命令为 `py -3.12 -m uvicorn server:app --host 127.0.0.1 --port 8000`；本地 Streamlit 为 `py -3.12 -m streamlit run app.py`。
2. 自然语言演示需要在**服务端**配置 `DEEPSEEK_API_KEY`，可用 `DEEPSEEK_MODEL` 选择模型。不要将密钥放进页面、截图、提交记录或下载结果。
3. 打开 Web 页面，确认首页显示“模拟数据演示”，并看到 18 个搜索目的地、264 条报价和 2027 年 10 月的范围。
4. 没有模型配置或模型调用失败时，示例与手动输入仍可演示完整的确认、搜索、比较流程；如实说明该轮没有调用模型。

[公开演示](https://travel-route-poc.vercel.app) 已于2026-09-22核验；演示前可检查首页和 `/api/health`，或使用上述本地地址。

## A. 自然语言到可编辑确认

在“说说你的想法”中粘贴：

> 10月从上海出发，12到18天，仙本那一定要去，也想去巴厘岛，单人机票预算9000以内，喜欢潜水和海岛，每程最多中转一次，不接受自行转机。

点击“整理我的旅行想法”。此时只能出现条件草稿，不应自动出现路线。检查日期、机场、预算、必去和优选地点、偏好，以及列出的假设和不确定项。

这段描述没有年份。“上海”也不自动等于用户已明确指定浦东机场。根据当前草稿的空白与提示逐项处理：

- 将最早出发日期明确为 **2027-10-01**，最晚返回日期明确为 **2027-10-22**。
- 明确出发机场为 **PVG**；明确允许返回 **PVG、HGH、NKG**。不同返程机场是用户选择，不能直接从“上海出发”推断。
- 确认最短 **12 天**、最长 **18 天**，单人机票预算 **9,000 元**。
- 确认仙本那在“必去”，巴厘岛在“想去，但可以不去”。检查其他地点是否误入。
- 根据自己的偏好调整滑杆、可选地点上限和中转限制。最后勾选确认，再点击“确认条件，发现旅行组合”。

如果模型擅自补了年份或漏了必去地点，应现场指出并修正。不要将错误当成正确结果继续展示；这正是当前确认层需要覆盖的风险。若输出未通过本地草稿校验，页面应提示失败并保留手动入口。

Web 页面会在修改原文或确认字段后清除旧结果，并要求重新确认；Streamlit 在修改原文后清除旧草稿与结果。可以输入“预算改成 5,000”验证旧结果不会继续被当成新请求的答案。

## B. 固定条件下复现路线比较

点击右侧“海岛潜水｜仙本那必去”示例。该入口直接载入结构化示例，**不消耗模型调用，也不代表刚刚完成了 AI 抽取**。检查以下固定条件：

| 字段 | 固定值 |
| --- | --- |
| 出发 | PVG |
| 返程 | PVG、HGH、NKG |
| 日期窗口 | 2027-10-01 至 2027-10-22 |
| 总行程 | 12–18 天 |
| 单人机票预算 | CNY 9,000 |
| 必去 | 仙本那 |
| 优选 | 巴厘岛、宿务 |
| 偏好权重 | 海岛 95、潜水 100、美食 45、文化 10、自然 75、城市 5、放松 60 |
| 可选目的地上限 | 3 |
| 每张单程报价最多中转 | 1 |
| 自行转机 | 不允许 |

不修改这些字段，勾选确认并生成方案。当前固定数据的参考结果是 **16 条可行行程、8 条 Pareto 行程、展示 5 条代表方案**。这些计数来自现有算法计算，用于回归核对；没有写入优化器作为答案。

| 代表方案 | 路线 | 模拟机票 | 交通总时长 |
| --- | --- | ---: | ---: |
| 最便宜 | PVG → 仙本那 → HGH | ¥1,726 | 17 小时 |
| 最少折腾 | PVG → 仙本那 → 吉隆坡 → NKG | ¥2,438 | 约 16 小时 19 分钟 |
| 综合推荐 | PVG → 仙本那 → 巴厘岛 → HGH | ¥2,235 | 约 18 小时 2 分钟 |
| 偏好最匹配 | PVG → 仙本那 → 巴厘岛 → 普吉岛 → NKG | ¥3,532 | 约 25 小时 38 分钟 |

说明这个具体取舍：“本轮最少折腾方案的模拟机票比最低价高 712 元，交通时间少约 41 分钟，同时增加吉隆坡并改变了返程机场。是否值得，取决于你对体验、交通和回家机场的选择。”负担分还包括飞行日、中转和夜航，不等同于仅按交通小时排序。

不要说“现实中省了多少钱”。对比表只比较本轮同条件、同模拟报价的方案。

## C. 展开解释与目的地档案

打开一条路线的“查看航班、停留与目的地资料”：

1. 检查每段航班、日期、价格、中转和模拟来源。
2. 阅读目的地类型、适合活动、建议季节与交通难度。
3. 区分两类信息：优化数据中的建议夜数、季节分和接驳时间参与计算；目的地描述、更新时间和可信度帮助理解，不参与优化。
4. 指出描述档案也标记为模拟、未经核实；不能把它作为可直接执行的旅行指南。

Web 可以下载本轮对比 JSON，便于保留已确认的条件、方案和数据版本。下载内容不包含模型密钥。Streamlit 保留匿名反馈记录下载，其内容只用于按既定研究流程另行开展的测试；演示操作本身不构成用户验证。

## D. 无解和覆盖不足

在固定潜水示例中，将预算改为 **1 元**，重新勾选确认并搜索。应显示当前模拟报价下没有可行行程，且没有自动放宽日期、预算、必去地点或中转限制。

恢复示例后，选择标有“暂无演示报价”的目的地作为必去，说明“目录有资料”和“本轮有报价”是不同边界。无解不代表现实中没有航班，也不应自动移除该必去地点。

日期超出数据覆盖时，应显示校验或覆盖提示；讲解时不要把无效请求描述成模型能力或算法推荐结果。

## E. 本地 Streamlit 对照

1. 默认“发现模式”选择“海岛与潜水”等示例文字，点击“AI 提取旅行条件”。
2. 在“检查并修正旅行条件”中修改字段。缺失日期、天数或预算应保持空白；未补全不能开始搜索。
3. 勾选逐项确认；若存在未解决内容，再明确确认如何处理。自行转机要求必须由用户主动取消，系统不会静默修改。
4. 点击“确认条件并生成多个方案”，查看相同引擎生成的对比和解释。
5. 切换“手动规划模式”，选择固定“海岛潜水｜仙本那必去”场景，点击“开始优化”，可核对上述固定结果。

模型不可用时，直接从第 5 步完成算法与比较展示，并明确标识这次使用结构化输入。
